The Javadoc for every public class of the Veeplay Android SDK is published at <a href="/android-player/">docs.veeplay.com/android-player/</a>.

It documents `APSMediaPlayer` (the player), `APSMediaBuilder` (JSON configuration and playlists), `APSMediaUnit` and `APSVastAdBreak` (content and ads), the overlay controllers, `APSMediaTrackingEvents` (the events you can listen to) and the Cast classes.

Related references:

- [JSON configuration reference](/json-configuration/): every option of the JSON configuration, shared by all Veeplay players.
- [Events reference](/docs/video-player/events): the tracking events and their platform support.
